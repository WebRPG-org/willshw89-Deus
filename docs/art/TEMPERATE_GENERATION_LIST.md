## 2. Priority list of new generation

How to read it:

- **One run** is one prompt in one tool call. The candidates it returns are alternatives: keep one (Tiles Pro: keep all 16 tiles). A value in `[A / B / C]` means one separate run per value: paste that value in and delete the rest. Exception, the ramp rows 3.09-3.24: only the direction and profile brackets make separate runs (4 directions x 5 profiles = 20 per material). The canvas and envelope brackets follow the chosen profile: C1-C2 take the 96x96 canvas, C3-C5 the 144x144 canvas, each with its own envelope (C1 48x67, C2 48x86, C3 48x105, C4 48x124, C5 48x144). Paste only the matching value.
- **Tile prompts start with the terrain pair.** The merge puts the pair before the style paragraph. PixelLab may put either terrain on tile 0 or tile 15; the PM checks which is which.
- **Presets.** T48 = Tiles Pro: view high top-down, 48 px, outline off, segmentation off, tile thickness 0 (flat, not a raised block), one set, no extra variations. T48w = T48 with segmentation on and no style reference (the water cards). O48, O96 and O144 = Objects: view high top-down, square canvas of that size, selective outline (no heavy outline), medium detail, transparent background with binary alpha, one whole subject, no sheet. Selective outline stays only on free-standing pieces: hanging pieces (4.16-4.18), connectors (4.22-4.28) and creatures (group 7); the still effects (4.19-4.21, 5.06) keep the preset too. "Outline off" is noted in the settings cell where it applies: the flat overlays and marks (4.01-4.09, 6.01-6.07) and the tile-like faces, ramps, wall panels and inner walls (3.01-3.26, 4.10-4.15). The SOP gives terrain no outline (AS-LOCK-001, AS-DEPTH-001) and treats cliff and wall pieces as terrain tiles (AS-PROJ-001, AS-QTR-001; their catalogue rows are groupType TILE). They sit side by side, so a 1 px border on each would draw a dark seam every 48 px. Their prompts say instead that edges meeting neighbouring faces or the ground top stay open and that a 1 px ledge rim highlight is allowed (AS-DEPTH-001).
- **Style references** name the accepted specimen by id. "Fill tile N" says which of its 16 PNGs to use.
- **No colour count in prompts.** The SOP says prompts do not state a colour count (AS-LOCK-001). Colour caps (about 48 for a tileset, 32 for a creature, 16 for a small item) are a machine-QA check, not prompt text.
