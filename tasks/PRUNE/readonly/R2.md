## 3. Critical Keepers Confirmation

### A. `DEUS_Minimap.js` -> MUST STAY IN `game/js/plugins/`
- **Location:** `game/js/plugins/DEUS_Minimap.js` (exists, 577 lines).
- **Referenced by Active Plugin:** `game/js/plugins/DEUS_Camera.js:621-626`
  ```javascript
  // Dynamically load DEUS_Minimap if not already loaded
  if (typeof PluginManager !== "undefined" && typeof PluginManager.loadScript === "function") {
      if (!PluginManager._scripts || (!PluginManager._scripts.includes("DEUS_Minimap") && !PluginManager._scripts.includes("DEUS_Minimap.js"))) {
          PluginManager.loadScript("DEUS_Minimap");
      }
  }
  ```
- **Consequence of Removal:** If `DEUS_Minimap.js` is moved or deleted, `DEUS_Camera.js` invokes `PluginManager.loadScript("DEUS_Minimap")` during RMMZ startup, triggering an unhandled HTTP 404 / script loading error that halts the game client.
- **Verdict:** **MUST STAY.** Do not move or archive.

### B. `game/js/sim/hydro/` -> MUST STAY
- **Location:** `game/js/sim/hydro/index.js` (exists, authoritative fluid simulation kernel).
- **Referenced by Active Plugin:** `game/js/plugins/DEUS_Fluid.js:984`
  ```javascript
  function loadHydroModule() {
      if (hydroMod !== undefined) return hydroMod;
      hydroMod = null;
      if (typeof require !== "function") return null;
      try {
          const mod = require("../sim/hydro/index.js");
          if (mod && typeof mod.createSession === "function") hydroMod = mod;
      } catch (e) {
          hydroMod = null;
      }
      return hydroMod;
  }
  ```
- **Consequence of Removal:** Fluid simulation session integration fails, disabling the upstream 0..7 shallow-water and hydrostatic solver in `DEUS_Fluid.js`.
- **Verdict:** **MUST STAY.** Do not move or archive.
